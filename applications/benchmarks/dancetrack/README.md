# dancetrack

40 sequences of the DanceTrack set, `dancetrack0001` to `dancetrack0099`, in `data/`. Dancers
look alike and cross each other, which tests association more than detection.

```bash
st eval --benchmark dancetrack --compare
```

Git does not track `data/`. The sequences come from https://github.com/DanceTrack/DanceTrack and
keep their own licence.
